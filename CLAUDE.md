# usd-bridge

Кросс-курс между двумя валютами через доллар — по курсам, которые пользователь
вводит сам. Local-first PWA, без бэкенда, работает офлайн.

## Перед работой — прочитай

- **`PLAN.md`** — продуктовый и технический спек: модель расчёта, поведение
  в краевых случаях, все принятые решения и таблица отвергнутого с причинами.

## Ключевые правила

- Node 24 (`.nvmrc`, `nvm use`), **pnpm**, React 19 + TS strict, Vite, Vitest.
- **React Compiler включён** (`react({ compiler: true })` на oxc). Не писать
  `useMemo`/`useCallback`/`memo` руками — этим занимается компилятор.
  Его линт-правила живут в `eslint-plugin-react-hooks`.
- Чистая логика — в `src/core/`: ноль React, покрыта Vitest. Тесты пишем
  **только на неё**; компоненты и e2e не тестируем.
- Стили: нативный CSS + **БЭМ**, без препроцессоров. Элементы (`block__elem`)
  не вкладывать — отдельные селекторы верхнего уровня. Цвета — только через
  токены из `src/styles/tokens.css`.
- Тема — по системе, переключателя нет: светлая на `:root`, тёмная
  в `@media (prefers-color-scheme: dark)`.
- Local-first: ноль сетевых запросов в рантайме. Шрифты лежат в репозитории
  (`src/styles/fonts/`), а не на CDN.
- Источник правды состояния — **хеш в адресе**, `localStorage` только кэш.
- Коммиты делает пользователь — не коммитить без явной просьбы.

## Команды

```
pnpm dev         # Vite dev-сервер
pnpm test        # Vitest (только src/core)
pnpm lint        # ESLint, включая правила React Compiler
pnpm typecheck   # tsc --noEmit
pnpm build       # прод-сборка
pnpm deploy      # сборка + wrangler deploy
```

## Правило интерфейса

После числа стоит то, что объясняет число: у курса — обозначение валюты,
у комиссии — переключатель `%`/`фикс`. Строка должна читаться вслух
(«90 ₽ за 1 $»). Подпись поля называет то, что в поле лежит: там курс,
а не сумма, поэтому «У меня», а не «Отдаю».

Кольцо фокуса рисует `.field__row:focus-within` — одно на всю строку.
На самих `input` внутри строки `outline` снят, иначе получаются два контура.

Валюта выбирается, а не печатается: `₫` нет на клавиатуре iPhone. В состоянии
лежит **код ISO 4217**, символ выводится из него при отображении — подпись
не может разойтись с выбором. Список берётся из `Intl`, своей таблицы валют
заводить не надо.

Замена валюты стирает курс этого плеча (`applyCurrency` в `src/core/state.ts`):
число принадлежало прежней валюте. Правила, которые удаляют пользовательский
ввод, живут в `core/` и покрываются тестами — не в компонентах.

Отступы с безопасной зоной пишутся сложением, а не `max()`: `max()` съедает
обычный отступ и прячет нижние элементы под панель Safari.

## Грабли, на которые уже наступили

- `Date.now()` **нельзя звать в рендере** — React Compiler это ловит.
  Момент открытия зафиксирован в модульной константе `OPENED_AT` в `App.tsx`.
- В цепочке `--font-mono` после JetBrains Mono стоит Ubuntu: в сабсетах
  моноширинного нет latin-ext, где живут `₽` и `₫`.
- Конфиг `eslint-plugin-react-hooks` брать из `configs.flat[...]`:
  у `configs[...]` формат eslintrc, и `tseslint.config()` его не принимает.
